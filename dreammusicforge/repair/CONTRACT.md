# Repair Contract Truth Boundary

A repair contract is derived only from an evidence-bearing VerificationReport.

It may:
- preserve passing dimensions,
- authorize bounded changes to failed dimensions,
- route unresolved evidence to review,
- return unbounded failures to Production Strategy.

It may not:
- silently change Film Genome,
- silently change Experience Graph,
- silently change Production Twin state,
- erase failed verification evidence,
- promote a repaired asset without re-verification.

Every repaired candidate must re-enter Render Intake & Verification as a new candidate with new evidence and hash lineage.

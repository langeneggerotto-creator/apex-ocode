# DreamMusicForge Research Program

```text
research/
├── hypotheses/
├── benchmarks/
├── experiments/
├── failures/
├── discoveries/
└── papers/
```

Every research item must state the question, hypothesis, prior evidence, method, falsification conditions, expected information gain, actual result, confidence update, limitations, and canonicalization decision.

Aesthetic preference alone is not evidence. Benchmark claims must identify source assets, timestamps, extraction method, metrics, reviewer assumptions, and reproducible artifacts.
